# 医療情報をメインテーブルへ移行する手順

1. GitHubリポジトリの既存ファイルを、このZIP内の `app.js` と `index.html` で置き換えます。
2. Supabase SQL Editorで `medical_main_table_migration.sql` を全文実行します。
3. GitHub Pagesの更新後、PWAを再読み込みして猫の詳細画面の「医療情報を編集」から保存をテストします。

このSQLは `cats` に医療カラムを追加し、`vaccinations` / `virus_tests` / `surgeries` の記録行を削除します。猫・プロフィール・写真・観察日記・譲渡記録は削除しません。医療履歴テーブル自体は残してあるため、アプリが正常動作することを確認した後で別途整理できます。

注意：指定により医療履歴の既存行は削除され、復元できない場合があります。実行前にSQLが対象のSupabaseプロジェクトであることを確認してください。


変更：手術項目は「不妊去勢手術日」のみとし、「手術内容」は廃止しました。SQL実行時に cats.surgery_type カラムも削除します。
