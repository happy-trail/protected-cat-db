# DB設計整理（死亡情報の専用記録を廃止）

## 方針
- 猫の状態 `cats.status` の選択肢「死亡（`deceased`）」だけで管理する。
- 死亡日、死因、死亡時の動物病院、死亡時メモは入力・表示しない。
- `deaths` テーブルは既に存在しないことを確認済み。
- 観察日記の通常記録と保護時記録は維持する。
- 既存の観察日記、監査ログ、猫の状態は削除・変更しない。

## 適用手順
1. このZIPのファイルをGitHub Pagesのリポジトリへ反映する。
2. PWAでログインし、猫の編集画面に状態選択だけが表示されることを確認する。
3. 通常の観察日記、保護時記録、PDF出力、権限別ログインをテストする。
4. アプリが正常に動作することを確認した後で、Supabaseの `observations` に残る死亡関連列を削除するか判断する。

## 注意
このZIPにはDBの列を削除するSQLを含めていません。PWAのコードを先に更新し、動作確認後にDB列の削除を別途行ってください。
